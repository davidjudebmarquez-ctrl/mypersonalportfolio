# CC102 Personal Portfolio

## Files
- `index.html` — portfolio content and navigation
- `style.css` — dark blue and white responsive styling
- `script.js` — mobile navigation and copy-code interaction
- `java/TicTacToe.java` — sample console Tic-Tac-Toe game source

## Before publishing
1. Open `index.html` and replace `Your Name` / `Your Full Name` with your preferred public display name.
2. Replace `your-email@example.com` with an email address you are comfortable sharing, or remove the email row.
3. Check the spelling of each school name against your official school records. The supplied list has been entered as provided.
4. Replace the sample Java code with your actual final CC102 PeTA source if it is different. The portfolio code section and `java/TicTacToe.java` should match.
5. Open `index.html` in a browser and test every navigation link and the Java download link.

## GitHub Pages
Upload the contents of this folder to the root of a public GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
